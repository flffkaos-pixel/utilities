모스 부호 사용 가이드Morse Code Guide

모스 부호입니다. 텍스트↔모스 부호 작업을 브라우저 안에서 처리하며, 설치 파일도 로그인도 없고 탭을 닫으면 입력한 값이 남지 않아 개인 자료를 다루기에 안심됩니다.Text to Morse code, right in your browser. Values update the result instantly, so you can tweak an input and see the new answer without clicking anything.

모든 처리는 현재 브라우저 탭 안에서만 이루어집니다.Everything happens inside the current browser tab.

입력과 처리가 같은 화면 안에서 끝납니다. 값을 넣으면 바로 계산이 이루어지고, 결과가 갱신될 때마다 서버 요청이 발생하지 않습니다. 값을 여러 번 바꿔 봐도 같은 방식으로 빠르게 반응합니다.Input and processing happen in the same window. Change a value and the result updates at once, with no server call behind the scenes, and it keeps responding just as quickly no matter how many times you try a different number.

사용법How to use it

  1. 인원수, 범위, 옵션이 있다면 먼저 정합니다.Set the count, range, or other options first, if there are any.
  2. 시작 버튼을 눌러 결과를 뽑습니다.Press the start button to get a result.
  3. 화면에 표시되는 결과를 확인합니다.Read the result shown on the screen.
  4. 마음에 들지 않으면 한 번 더 실행해 새 결과를 받습니다.Run it again if you want a different result.

결과는 엔터테인먼트 목적입니다. 무작위 결과를 중요한 결정의 유일한 근거로 삼지 않는 것을 권장합니다.The output is for entertainment. Do not let a random draw be the only reason behind an important decision.

자주 묻는 질문Frequently asked questions

결과는 어디에 저장되나요?Where is the result stored?

모스 부호의 결과는 화면에만 표시됩니다. 탭을 새로고침하면 입력한 값도 함께 초기화되며, 기록이 필요하면 결과를 복사해 문서나 메모에 남기세요.The result only appears on screen. Refreshing the tab clears your input too, so copy the result into a document if you need a record.

이 도구와 시저 암호의 차이는 무엇인가요?How is this different from Caesar Cipher?

두 도구의 초점이 다릅니다. 하나는 암호화/복호화 작업용이고, 다른 하나는 텍스트↔모스 부호 작업용입니다. 두 도구를 함께 열어 두면 작업 흐름이 끊기지 않습니다.They focus on different jobs: one is for Encrypt/decrypt text, the other for Text to Morse code. Keep both open and your workflow will not break stride.

결과를 그대로 써도 되나요?Can I use the result as it is?

결과는 엔터테인먼트 목적입니다. 무작위 결과를 중요한 결정의 유일한 근거로 삼지 않는 것을 권장합니다.The output is for entertainment. Do not let a random draw be the only reason behind an important decision.

홈 화면 검색창에 도구 이름을 입력하면 바로 나옵니다. 또는 홈의 엔터테인먼트 도구 카테고리에서 시저 암호, 숫자→문자 변환, 템포 측정기(탭 BPM) 같은 도구를 한 번에 볼 수 있습니다.Type the tool name into the search box on the home page, or open the Entertainment tool category there to see Caesar Cipher, Number to Words, BPM Tapper side by side.
