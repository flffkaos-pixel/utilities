URL 슬러그 생성기입니다. URL 친화적 슬러그 변환 같은 기능을 제공하며, 입력한 값은 서버로 전송되지 않고 내 기기 안에서만 처리됩니다.Generate URL-friendly slugs. Open the page, fill in the fields described below, and read the result straight away; your input never leaves the device.

계정을 만들 필요가 없어 몇 초면 바로 결과를 받을 수 있습니다.It is completely free, with no usage cap and no paywall.

구분자 값을 넣으면 계산이 바로 이루어지고, 결과가 갱신될 때마다 서버 요청이 발생하지 않습니다. 최대 길이 값을 여러 번 바꿔 봐도 같은 방식으로 빠르게 반응합니다.Put in Separator and the calculation runs straight away; every time the result refreshes there is no server request behind it. Change Max length as often as you like and the response stays just as fast.

사용법How to use it

  1. 상단 입력칸에 구분자 값을 입력합니다.Enter the Separator value in the field at the top.
  2. 최대 길이 값을 함께 입력합니다.Enter Max length as well.
  3. 결과는 입력이 바뀌는 즉시 갱신됩니다. 값을 조정해 가며 원하는 결과를 확인하세요.The result refreshes as soon as a value changes - adjust the inputs until it looks right.

  • 구분자 값만 바꿔도 결과가 달라지는 경우를 비교할 때.Comparing what changes when only Separator moves.
